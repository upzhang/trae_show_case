# 发布与变更记录规范

## 发布对象

"发布记录"（`ReleaseRecord`）代表一次软件版本的部署或回滚。

关键字段：

- `version`：版本标识，例如 `2026.06.01`
- `environment`：`staging` | `production`
- `status`：`pending` | `deployed` | `rolled_back`
- `operatorId`：操作人用户 ID
- `createdAt`：操作时间（ISO 字符串）

## 操作流程

1. 以发布经理身份登录
2. 在"发布记录"页点击发布或回滚
3. 后端更新状态并写入审计日志
4. 回滚仅允许对已部署记录执行，重复回滚无副作用（需要状态机校验）

## 发布记录展示

- 表格按时间倒序
- 状态使用 badge 样式
- 只有 `release:deploy` 权限的用户能看到"发布/回滚"按钮

## 注意事项

- 发布记录与审批是独立模块：审批不阻塞发布
- 发布/回滚操作必须写入审计日志，摘要需说明版本、环境与操作
- 测试数据环境下，发布记录不会真正触发部署
