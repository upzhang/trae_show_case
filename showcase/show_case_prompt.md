# 演示场景提示词

## 场景 1：项目理解
```
切换到git标签：showcase1-项目理解前，按README.md的提示词进行操作
```

## 场景 2：测试用例补全

```
项目中缺少了部分测试用例，请根据项目的路由文件、服务文件和现有测试风格，补全缺失的测试用例。
```

## 场景 3：一键执行所有 API 测试用例

```
执行项目中所有 API 测试用例，汇总每个测试文件的 PASS/FAIL 结果到showcase目录 result_api_test_YYYYMMDDhhmmss.md 文件。
```

## 场景 4：单页面深度黑盒测试

```
审批中心页面黑盒测试，输出截图及其对应的操作说明，到showcase目录 result_blackbox_YYYYMMDDhhmmss.md 文件。
```
