# Nexus 客户运营管理台 — 用户手册

## 1. 快速入门

### 1.1 启动系统

```bash
cd trae-enterprise-validation-demo
pnpm install
pnpm dev:api    # 启动后端 API（端口 3001）
pnpm dev:web    # 启动前端管理台（端口 5173）
```

浏览器打开 `http://localhost:5173` 即可访问。

### 1.2 切换用户身份

系统预置了多个角色的演示用户，右上角下拉框可直接切换：

| 用户 | 角色 | 说明 |
|------|------|------|
| platform@example.com | 平台管理员 | 全部权限，可管理所有租户和用户 |
| 苏嘉宁 | Acme 租户管理员 | 管理本租户的用户、审批、发布 |
| audit@example.com | 审计员 | 只读访问，可导出审计日志 |
| release@example.com | 发布经理 | 审批和发布操作 |
| 周然 | Orbit 客户管理员 | 另一个租户的管理员 |
| 陈屿 | Nova 运营成员 | 普通成员，最小权限 |
| 方澜 | Nexus Health 客户管理员 | 第三个租户的管理员 |

也可以通过输入邮箱搜索并切换到任意用户。

## 2. 工作区

### 2.1 工作台 / 总览（`/`）

**页面功能**：展示平台核心运营指标和最近活动。

**操作指南**：
1. 顶部指标卡片展示：租户总数、活跃用户、审批通过率、本月收入
2. 三个趋势图：租户增长趋势、审批量趋势、发布量趋势
3. 客户健康分布：进度条展示健康/观察/风险客户比例
4. 最近活动时间线：展示最近的用户、审批、发布、审计、风险、工单活动
5. 快速操作入口：创建用户、发起审批、查看风险

**权限要求**：所有角色可访问（数据范围因角色而异）

---

### 2.2 客户 / 租户（`/tenants`）

**页面功能**：管理所有租户（客户），查看客户画像。

**操作指南**：
1. 顶部统计卡片：租户总数、平均健康分、总 ARR
2. 搜索框：按租户名称搜索
3. 筛选栏：按套餐类型筛选（全部/企业版/标准版/初创版）
4. 排序：按名称、健康分、ARR 排序
5. 点击租户行 → 打开详情 Modal：健康分、ARR、订阅状态、合同到期日、CSM 负责人、席位使用量
6. 创建租户按钮（需 `tenant:write` 权限）

**权限要求**：
- 查看列表：所有角色
- 创建租户：需 `tenant:write`（仅 platform_admin）
- 编辑/删除：需 `tenant:edit` / `tenant:delete`（仅 platform_admin）

---

### 2.3 用户与权限（`/users`）

**页面功能**：管理平台用户，分配角色。

**操作指南**：
1. 顶部统计卡片：用户总数、活跃用户、租户管理员数
2. 搜索框：按姓名或邮箱搜索
3. 筛选栏：按角色筛选（全部/平台管理员/租户管理员/审计员/发布经理/成员）
4. 用户列表：展示姓名、邮箱、角色标签、所属租户、状态
5. 创建用户：点击"创建用户"按钮 → 填写姓名、邮箱、选择角色 → 保存
6. 编辑角色：点击用户行的"角色"按钮 → 在 Modal 中添加/删除角色 → 保存
7. 查看详情：点击用户行 → 打开详情 Modal（角色列表、所属团队、最近活动）
8. 批量操作：勾选用户 → 批量启用/禁用
9. 删除用户：点击删除按钮 → 确认弹窗 → 确认删除

**权限要求**：
- 查看列表：需 `user:view`
- 创建用户：需 `user:write`
- 编辑角色：需 `role:edit`（仅 platform_admin）
- 删除用户：需 `user:delete`

---

### 2.4 角色权限（`/roles`）

**页面功能**：管理 RBAC 角色定义和权限矩阵。

**操作指南**：
1. 角色卡片列表：展示 7 个预置角色（5 个系统角色 + 2 个自定义角色）
   - 系统角色（灰色背景）：不可删除
   - 自定义角色（白色背景）：可编辑、可删除
2. 查看权限：点击角色卡片的"编辑"按钮 → 打开权限矩阵 Modal
   - 56 个权限码按 16 个权限组展示
   - 已分配的权限显示为勾选状态
3. 创建自定义角色：点击"创建角色"按钮 → 填写名称、描述 → 勾选权限 → 保存
4. 克隆角色：点击角色卡片的"克隆"按钮 → 自动填充"XX (副本)" → 修改后保存
5. 删除角色：点击自定义角色的删除按钮 → 确认后删除（系统角色不可删除）

**权限要求**：
- 查看列表：需 `role:view`
- 创建/编辑/删除：需 `role:write` / `role:edit` / `role:delete`

---

### 2.5 团队管理（`/teams`）

**页面功能**：管理团队组织架构。

**操作指南**：
1. 团队列表：展示团队名称、描述、成员数、状态
2. 创建团队：点击"创建团队"按钮 → 填写名称、描述 → 保存
3. 查看详情：点击团队行 → 查看成员列表
4. 编辑团队：修改名称、描述
5. 删除团队：点击删除按钮 → 确认后删除

**权限要求**：

- 创建/编辑/删除：需 `team:create` / `team:manage`

## 3. 运营

### 3.1 审批中心（`/approvals`）

**页面功能**：管理审批工作流，发起和审批请求。

**操作指南**：
1. 顶部统计卡片：待审批数量、已通过数量、已拒绝数量
2. 状态 Tab 筛选：全部 / 待审批 / 已通过 / 已拒绝
3. 审批列表：展示标题、状态、申请人、创建时间
4. 发起审批：点击"发起审批"按钮 → 填写标题和描述 → 提交
5. 审批操作：点击"通过"或"拒绝"按钮
6. 查看详情：点击审批行 → 打开详情 Modal（审批链、时间线、决策历史）

**权限要求**：
- 查看列表：需 `approval:view`
- 发起审批：需 `approval:write`
- 审批操作：需 `approval:approve`

## 8. 常见问题

### Q: 为什么有些按钮看不到？
A: 按钮可见性由当前用户的角色权限决定。切换右上角的用户身份可以看到不同角色的权限差异。

### Q: 为什么创建用户时角色保存失败？
A: 修改用户角色需要 `role:edit` 权限，仅平台管理员有此权限。租户管理员无法修改用户角色。

### Q: 为什么审批不能重复操作？
A: 审批状态机只允许对 `pending` 状态的审批进行操作。已通过或已拒绝的审批不可重复操作，会返回 409 错误。

### Q: 系统角色和自定义角色有什么区别？
A: 系统角色（platform_admin、tenant_admin、auditor、release_manager、member）不可删除，权限固定。自定义角色可以自由配置权限组合，可以克隆系统角色后修改。

### Q: 数据存储在哪里？
A: 当前版本使用内存存储，重启后数据会重置为预置种子数据。生产环境需接入持久化数据库。
