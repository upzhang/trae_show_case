# Nexus 客户运营管理台

一套完整的多租户 SaaS 运营管理后台，用于验证 Trae 在企业级研发场景中的全栈能力。

## 项目规模

| 指标 | 数值 |
|------|------|
| 总代码行数 | **30,000+ 行**（TypeScript + TSX + CSS） |
| 功能页面 | **20 个**（五大业务分组） |
| API 路由 | **18 个**模块 |
| 后端服务 | **16 个**服务层 |
| 测试用例 | **355 个**（13 个测试文件） |
| 前端组件 | **33 个**可复用组件（含 4 个 SVG 图表组件） |

## RBAC 权限体系

| 角色 | 说明 | 典型权限 |
|------|------|----------|
| platform_admin | 平台管理员 | 全部 56 个权限码，可管理所有租户和用户 |
| tenant_admin | 租户管理员 | 管理本租户用户、审批、发布、订阅 |
| auditor | 审计员 | 只读访问所有模块，可导出审计日志 |
| release_manager | 发布经理 | 审批操作、部署与回滚发布 |
| member | 普通成员 | 最小查看权限，仅可查看列表 |

前后端基于共享权限矩阵（`packages/shared/src/rbac.ts`）统一判断，前端按钮可见性由 `can()` 控制，后端接口由 `requirePermission()` 中间件拦截。

## 技术架构

```
trae-enterprise-validation-demo/
├── apps/
│   ├── api/          # Express + TypeScript 后端 API
│   └── web-admin/    # React + TypeScript 前端管理台
├── packages/
│   └── shared/       # 共享类型、RBAC 模型、权限矩阵
├── tests/
│   └── api/          # 13 个集成测试文件（Vitest + Supertest）
├── knowledge-base/   # 企业知识库（8 份文档）
└── verification/     # 验证清单与示例任务
```

## 快速开始

```bash
# 安装依赖
pnpm install

# 启动后端 API（端口 3001）
pnpm dev:api

# 启动前端管理台（端口 5173）
pnpm dev:web
```

## 测试

```bash
# 运行全部测试（355 个用例）
pnpm test

# 仅运行 API 测试
pnpm test:api

# 类型检查
pnpm typecheck
```

## 演示数据

项目使用内存存储，预置了 7 个用户、4 个租户、多种角色和业务数据。前端右上角下拉框可切换用户身份，体验不同角色的权限差异。

## 企业能力验证

本项目预置了完整的 Trae 企业能力验证体系：

- **知识库**（`knowledge-base/`）：产品概述、RBAC 矩阵、API 契约、前后端规范、测试策略、发布手册、事件手册
- **验证清单**（`verification/trae-enterprise-checklist.md`）：6 大类 12 项验证场景
- **示例任务**（`verification/sample-prompts.md`）：6 个可直接交给 Trae 执行的任务
- **工程规范**（`.trae/rules/`）：工程规范、测试规范、安全规范
